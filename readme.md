
# Week 6 Homework: Python README File Generator.

## Description

The Python README File Generator is an application that automatically creates a README.md file for a GitHub repository. It simplifies the documentation process by prompting users for key project details and formatting them into a clean README file.

## Installation Instructions

To install and run this locally, clone the repository to your machine and navigate to the project directory.

## Usage Information

Run the following command in your terminal: 'python main.py'. Follow the prompts in the command line to enter your project information. After completion, the application will generate a README.md file automatically.
